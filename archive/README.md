# Release Archive

This directory preserves development material that is not part of the active
Cosmik M1N1 1.0.0 release.

- `uf2-experiments-0.1.x/`: every pre-release firmware image.
- `fallbacks/`: source and firmware snapshots kept during development.
- `test-midi/`: the CC1/internal-LFO DAW test clip.
- `EXPERIMENT_NOTES_0.1.x.md`: the original Web-Presets experiment notes.
- `legacy-web-presets-experimental/`: the earlier separate experimental
  checkout, retained as a source snapshot. `history.bundle` preserves its Git
  history without making the archive a nested Git repository.

The only firmware intended for normal flashing is
`../uf2/COSMIK_M1N1_1.0.0.uf2`.
